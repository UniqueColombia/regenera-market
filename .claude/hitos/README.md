# Hitos

Trazabilidad del proyecto. Un archivo por hito: qué se hizo, quién lo hizo, por
qué así, y qué quedó pendiente. Existe para que `CLAUDE.md` guarde solo la
infraestructura y no se convierta en un diario.

**Cómo escribir uno:** carga la skill `registrar-hito`, copia `_plantilla.md`.
**Un hito no se edita ni se borra.** Si cambió la decisión, se escribe otro que
referencie al anterior.
